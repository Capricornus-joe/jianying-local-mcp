# AI 用剪映自动剪片

**Jianying Local MCP** · 让 AI 把本地视频、照片、字幕和音乐剪进 Mac 剪映时间线。

[看案例怎么做](docs/case-study.md) · [开始使用](docs/quickstart.md) · [工具文档](docs/tools.md) · [English](README.en.md)

## 先看一支片子

这是我做的《入戏·川剧初体验》。不到一分钟，从看戏、变脸、吐火，剪到换装和亲自体验。照片、书法、字幕、配乐，都在剪映时间线上。

https://github.com/user-attachments/assets/8ad915ff-f449-415f-b163-cdf41901cca6

[备用播放 / 下载](docs/assets/showcase-preview.mp4) · 成片 59.52 秒 · 1080p · 25 fps（网页预览为 720p）

我觉得，这支片子已经有认真学一年剪辑的完成度了：画面有统一的风格，照片有进出的节奏，字幕也能跟着旁白走。当然，水平怎么样，还是看成片最直接。

我想让 AI 真正帮忙剪片：安排镜头顺序、设置素材入点、加字幕、做画面运动，再把这些操作落到剪映时间线上。做完还能打开工程，改字、换镜头、细调节奏。

这套流程里，**AI 客户端负责制定剪辑计划并调用工具，MCP 负责生成和修改剪映草稿，最后在剪映里检查、导出**。它通过草稿文件完成编辑，目前没有接管剪映里的全部鼠标操作。

这支案例从原始素材逐层搭建，精修还用了包外脚本。它展示了这套做法能走到哪一步；**目前还不能只装好 MCP、说一句话，就自动做出同样的片子。** [具体过程](docs/case-study.md)里写了哪些已经做成通用功能，哪些还在整理。

## 用关键帧让照片动起来

以照片进场为例：先放在画面外，稍微转一个角度，再让它滑到目标位置，同时放大、逐渐显现。位置、缩放、旋转、透明度分别写进剪映关键帧，照片就动起来了。

纸边和阴影也各占一层，跟着照片一起移动。案例里还把运动拆成更密的变化，让进场先加速、再慢慢停住；书法标题则按字错开出现时间。

![照片片段上的关键帧，以及剪映右侧的位置、缩放和旋转参数](docs/assets/jianying-animation.png)

*实际工程中的“言传身教”场景：照片片段上可以看到关键帧，右侧仍是剪映的位置、缩放、旋转设置。*

通用工具目前有 **9 种线性运动预设**，也能自定义关键帧。案例中的缓入缓出由专项脚本按 25 fps 采样实现，还没有做成通用的曲线编辑器。想看具体参数和做法，可以读 [动画拆解](docs/case-study.md#照片怎样动起来)。

## 普通字幕，直接用字幕做

错一个字，就改一个字。导入 SRT 后，每段字幕都是剪映里的文字片段；字号、颜色、位置、描边可以统一调整，也能单独修改某一句。

![在剪映原生文字面板里编辑普通字幕](docs/assets/jianying-subtitles.png)

*选中字幕后，右侧可以直接改字。这支片子的 28 句旁白，排成了 36 个原生文本片段。*

书法标题单独用了 PNG，保留字形和排版。它能移动、缩放、替换图片；普通字幕则保留逐字编辑。

## 时间线要让人接得下去

主时间线整理成 **23 个场景、6 条轨道**。想改某个场景，就打开它的复合片段：原始画面、纸边、阴影、书法分别摆放，旁白字幕和声音留在主时间线上。

![打开场景后，查看原始画面、纸边、阴影和书法的分层时间线](docs/assets/jianying-layers.png)

*“唱腔与身段”场景内部。双画面和装饰层各自独立，可以选中右侧镜头调整位置。*

MCP 可以命名轨道和片段、追加镜头、拆分片段、重新排序，或删除一段后收拢后续内容。案例的复合片段整理目前由包外脚本完成。

## 一轮改完，只存一个版本

改一句字幕、加粗、统一字号、加描边，再加个渐显——现在可以一次交给 `batch_edit`，最后只保存一个新版本。原版留着，中间五步不用各存一套工程和素材。

0.3.0 也减少了工具默认返回的数据，并缓存没有变化的素材信息。省下的是重复调用、重复探测和重复保存。[性能记录](docs/performance.md)里有测试范围和数据。

## 开始使用

需要 macOS、Python 3.11+，以及本机安装的剪映。

```sh
git clone https://github.com/Capricornus-joe/jianying-local-mcp.git
cd jianying-local-mcp
bash setup.sh
bash run.sh doctor
```

然后配置支持 MCP 的客户端，先创建一个纯文字草稿，再加入自己的素材。[快速开始](docs/quickstart.md)包含完整配置、第一份草稿和五步批量编辑示例。

## 现在能用到什么程度

当前有 **22 个工具**，通过本地 stdio 运行。MCP 编辑自己管理的计划，每次生成新版本；在剪映里手动改过的内容，目前不会自动同步回来。Mac 草稿兼容还在测试中，生成后需要在剪映里检查和导出。暂不支持读取加密草稿、任意修改已有工程，也没有可靠的 Mac 原生自动导出。具体版本和效果差异见 [兼容性说明](docs/compatibility.md)。
