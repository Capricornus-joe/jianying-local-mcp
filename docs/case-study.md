# 我让 AI 用剪映自动剪辑，做了一支国风川剧短片

《入戏·川剧初体验》把舞台、唱腔、身段、变脸和扮妆串成一段体验。成片为 **1080p、25 fps、59.52 秒**；剪映工程保留原素材、图层、关键帧和普通字幕，之后可以继续修改。

这里的自动剪辑，是由 AI 客户端安排镜头、字幕与动画，再通过 MCP 和案例脚本写入剪映草稿；预览、检查和导出仍在剪映中完成。

## 从原始素材重建

目标是参照已有成片，尽量按 1:1 重建它的构图、运动和节奏。制作时重新读取原始拍摄视频与照片，为每个镜头指定素材入点、时长、裁切和画面位置，再把旁白与配乐分别放入音轨。

朱红、米金和墨绿贯穿全片。照片、纸边、阴影、书法与纹样分别组织，方便调整构图，也让双窗和层叠照片保持一致的视觉风格。

## 照片怎样动起来

照片入场需要同时控制位置、旋转和透明度；缓慢推近、拉远则改变缩放，有时还要补偿构图中心的位移。这些数值写成剪映原生关键帧，进入工程后仍可调整。

通用 MCP 提供九种线性运动预设，包括推近、拉远、平移、滑入和渐显，也支持自定义旋转关键帧。案例中的缓入缓出由包外脚本计算：把时间归一化后，用 `t²(3−2t)` 算出运动进度，再按每秒 25 帧采样，写入位置、角度和透明度等关键帧。通用写入器负责连接这些数值点，本身没有提供这种缓动曲线预设。

## 纸边、影子与书法各有一层

一组照片通常拆成阴影、纸边和原素材三层，各层配合入场运动；书法和装饰使用独立的静态图片，可以移动、缩放或替换。普通字幕另用文字对象，书法图片不支持直接逐字改写。

为了便于接手，包外专项脚本将视觉图层按内容整理为 **23 个场景复合片段**。主时间线有 **6 条轨道**，分别容纳场景、字幕、闪光与片尾、姿态校正、旁白和配乐；进入场景后可以看到内部图层。通用 MCP 已支持多轨叠加，按场景生成这些复合片段尚属案例专项能力。

![进入“唱腔与身段”场景，查看原素材、相框、阴影与题字图层](assets/jianying-layers.png)

## 普通字幕可以直接改字

全片 **28 句旁白字幕，组织为 36 个原生文本片段**。文字内容、字号、颜色、描边、位置和起止时间都保留在工程中；选中字幕，就能在剪映文字面板里改字。

创建原生文字、导入 SRT 是通用 MCP 的能力。这支案例还通过专项脚本校准字体、描边和显示大小，并对照实际导出检查字幕出现与消失的帧。

![选中普通旁白字幕，右侧文字面板显示可编辑正文](assets/jianying-subtitles.png)

## 减少重复保存

v0.3 的 22 个工具覆盖草稿生成、普通编辑、SRT、关键帧、样式和媒体处理。`batch_edit` 可以把改文字、加粗、调字号、加描边、添渐显这五项操作先在内存中逐项校验，全部通过后只创建一个新版本，省去中间工程的复制和写盘。可运行示例见 [五步编辑，一次保存](quickstart.md#五步编辑一次保存)。

## 对照成片，保留限制

工程已在剪映中实际打开、编辑字幕并导出。最终成片做了全 **1488 帧**的自动时序与画面对比，再结合场景代表帧、字幕边界和局部修正进行人工目视核对；这不等于人工逐帧完整审看。

为对齐剪映的取帧与首次呈现行为，部分位置使用了从原始视频提取的完整帧图片，以及独立的原生姿态校正片段。这些补片保留原始画幅，没有合成整套排版和动画，但也让部分场景的时间线更细。

1:1 是重建目标，最终仍有字体栅格化、颜色采样和编码等细微差异，不能称为逐像素完全相同。**场景组合、字体精校、活动时间线同步和精确取帧修正使用了包外专项脚本，尚未全部纳入通用 MCP。** 本页展示的是实际完成的案例，不是安装 MCP 后一句话即可复现全部效果的承诺。
