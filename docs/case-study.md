# 案例拆解：《入戏·川剧初体验》

这支国风短片使用原始拍摄视频和照片制作。AI 编排镜头、字幕和动画，MCP 与案例脚本生成剪映工程，再在剪映中检查、调整和导出。

## 素材与剪辑结构

本次参照已有成片，用原始素材重建镜头和排版，目标是尽量还原构图、动画和节奏。每个镜头单独设置素材入点、时长、裁切和位置，旁白与配乐分轨处理。

全片共 23 个场景，主时间线分为 6 条轨道：场景、字幕、闪光与片尾、姿态校正、旁白、配乐。画面以朱红、米金和墨绿为主，照片搭配纸边、阴影和书法标题。

## 关键帧与缓动

照片动画主要使用四类参数：

| 参数 | 用途 |
| --- | --- |
| 位置 | 照片滑入、双画面位置调整 |
| 缩放 | 推近、拉远 |
| 旋转 | 照片倾斜、入场时的角度变化 |
| 透明度 | 渐显、渐隐 |

这些参数写成剪映原生关键帧。以照片滑入为例，先确定起点和终点的位置，再设置缩放、旋转和透明度。照片、纸边和阴影同步运动，避免边框与照片错位；缩放时还要补偿画面中心的偏移。

![照片片段上的关键帧及画面参数](assets/jianying-animation.png)

通用 MCP 提供 9 种线性运动预设，也支持自定义关键帧。这支案例的缓入缓出使用额外脚本计算：将时间归一化，用 `t²(3−2t)` 计算运动进度，再按 25 fps 采样并写入关键帧。目前还没有将这套缓动做成通用预设。

## 图层与复合片段

照片、纸边、阴影分别占用独立图层，书法和纹样也使用单独的静态图片。这样可以分别调整素材、装饰和题字的位置。

书法标题按字分层，并错开出现时间，形成逐字入场的效果。它们可以移动、缩放、替换，但不能像字幕一样直接改字。

案例脚本将视觉图层整理为 23 个场景复合片段。打开某个复合片段，就能调整内部素材；旁白、配乐和普通字幕留在主时间线上。通用 MCP 支持多轨叠加，自动按场景生成复合片段尚未集成。

![“唱腔与身段”场景内部的双画面及装饰图层](assets/jianying-layers.png)

## 字幕样式

28 句旁白字幕拆分为 36 个原生文字片段。字幕内容、字号、颜色、描边、位置和起止时间均可编辑。

普通文字创建和 SRT 导入由通用 MCP 完成。案例脚本另外校准了字体、描边和显示大小，并通过实际导出检查字幕的出现、消失时间。

![剪映原生文字面板中的旁白字幕](assets/jianying-subtitles.png)

## 批量编辑

以字幕修改为例，可以在一次 `batch_edit` 中依次修改文字、加粗、调整字号、添加描边和渐显。每一步在内存中校验，全部通过后才创建一个新版本，中间无需复制工程和素材。

完整参数见 [批量编辑示例](quickstart.md#批量编辑)。

## 导出与检查

工程已在剪映中打开、修改字幕并导出。最终成片进行了全部 1488 帧的自动时序与画面对比，并对场景代表帧、字幕边界和局部修正做了人工目视检查，未做人工逐帧完整审看。

为对齐剪映的取帧和首次呈现时间，部分位置补入了从原视频提取的完整帧图片，以及独立的原生姿态校正片段。补帧保留原始画幅，没有预先合成整套排版和动画。

重建目标是 1:1 还原，最终仍有字体渲染、颜色采样和编码差异，并非逐像素相同。缓动、场景复合、字体校准、活动时间线同步和取帧修正依赖额外脚本，当前通用 MCP 不能单独复现这支案例的全部效果。
