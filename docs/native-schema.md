# Mac 草稿生成器的范围与验证口径

`build_native(plan, project_dir)` 返回两份可序列化对象：`draft_info.json` 和 `draft_meta_info.json`。函数不读取文件、不调用剪映、不探测媒体、不复制素材、不修改草稿库，也不导出视频。输入只包含调用方明确提供的计划与媒体元数据。

此处是独立实现的结构生成器。已只读核对 Mac 草稿的字段层级、类型、空值和时间单位；未将旧草稿标题、文本、素材路径或任何设备标识放入代码或测试。`platform` 与 `last_modified_platform` 的设备标识均为空，`os` 固定为 `mac`。格式标记为 `version=360000`、`new_version=112.0.0`；v0.2 的 `app_version=11.4.0` 对应本次高级效果适配目标。标记本身不证明某份新工程已经通过应用验证。

## 计划到草稿的映射

- 输入时间使用秒，草稿时间使用整数微秒。`duration` 是时间线时长，视频/音频的源区间长度为 `duration × speed`；图像和文本要求 `speed=1`、`source_start=0`。
- 图片在 `materials.videos` 中登记为 `type=photo`；视频为 `video`，本地音频为 `extract_music`。同类同路径素材去重，裁剪不同的片段使用独立材质，避免相互影响；文件只复制一次。重复素材的时长和画面尺寸必须一致。图片的素材时长覆盖最长使用区间。
- 每条时间线片段的素材与附属引用均有对应对象。轨道按视频、音频、文本排列，同类轨道保留首次出现顺序。文本层位于视频上方。同轨重叠被拒绝。
- 文本保留为独立可编辑对象，支持颜色和标准化位置。`font_size` 输入采用像素意图，暂按 `size=font_size/6` 写入原生字号，48 对应 8；这是参考社区默认字号得出的初始换算，尚未校准所有画幅和剪映版本的实际显示。字体采用剪映默认字体。
- `draft_materials` 的 `type=0` 集合登记所有实际媒体，视频/音频/图片分别标记 `video`/`music`/`photo`。文本没有外部文件，因此不放入此媒体池。
- UUID 从计划 UUID 派生，同一输入可复现。媒体路径原样来自计划，必须为本地绝对路径；不会扫描系统或继承设备指纹。

## 调用方责任

调用方在调用前完成媒体探测与素材打包，并将计划路径指向最终可读取位置。Mac 剪映有沙盒文件权限限制，建议将媒体复制进项目的 `Resources/`，再生成这两份 JSON。

时间戳默认是 0，媒体总字节数默认是 0，因为本函数不读取时钟或文件信息。需要安装或排序时，调用方应在自己的写入阶段补充 `tm_draft_create`、`tm_draft_modified` 和媒体总字节数。封面为空；封面生成也由调用方负责。

2026-09-09 本机小样已经验证：未填入设备标识的生成草稿可以打开三轨、原生修改中文字幕并导出。v0.2 又经 MCP 发布并原生导出 16 秒高级样片。版本记录、画面参数和逐项证据见[兼容性与验证范围](compatibility.md)。程序测试证明结构与输入约束，原生结论来自独立应用实测，不能推广为全部版本兼容。已提供视觉关键帧、文字样式、音频淡入淡出、基础蒙版和已缓存动画/转场；未提供会员效果解锁、语音识别、加密读取或原生自动导出。

公开结构参考列于文末。当前 Mac 蒙版使用 `materials.common_mask` 和片段 `enable_video_mask=true`；文字范围使用 UTF-16 code units；线性关键帧时间相对片段起点。这些字段经过独立测试，并对具体样片做了原生复核。

## 公开格式参考

- [pyJianYingDraft 的文本格式](https://github.com/GuanYixuan/pyJianYingDraft/blob/main/pyJianYingDraft/text_segment.py)：用于核对独立文本对象及样式范围、填充颜色的字段含义。此生成器不依赖该库，也未复制其可执行实现。
